PLANTLAYOUT
===========
Aplicación web autocontenida para organizar el layout de una planta industrial mediante:
1) procesos y dimensiones
2) matriz de relaciones 0-3
3) diagrama de relaciones arrastrable
4) layout de bloques arrastrable y redimensionable

USO
---
Abre index.html con un navegador moderno (Chrome, Edge, Firefox).
No necesita instalación ni conexión a Internet.

FUNCIONES
---------
- Crear/eliminar procesos.
- Definir nombre, ancho y largo.
- Matriz simétrica de relaciones 0,1,2,3.
- Diagrama de relaciones con nodos arrastrables.
- Distribución inicial automática.
- Layout con bloques de tamaño proporcional a las dimensiones.
- Edición del elemento seleccionado.
- Métrica auxiliar de distancia ponderada.
- Guardado local en el navegador.
- Exportación/importación de proyectos JSON.
- Ejemplo de demostración.
